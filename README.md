## 快速开始（3 步）
1. 克隆仓库
   ```bash
   git clone https://github.com/autoMBD/AMBD-MC.git
   cd AMBD-MC
   ```
2. 安装依赖（举例）
   ```bash
   # 例如 Python
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. 运行示例
   ```bash
   python examples/run_demo.py
   ```
